# LinkTalk Releases / docs — dokumentacja wydań

To miejsce na **katalog oficjalnie opublikowanych paczek** i instrukcje przygotowania kolejnych wydań. Nie zawiera źródeł aplikacji React ani kodu Android.

| Potrzeba | Otwórz |
| --- | --- |
| Sprawdzić dostępne wydania i ich status | [KATALOG-WYDAN.md](KATALOG-WYDAN.md) |
| Bezpiecznie przygotować i opublikować nowy APK | [PROCEDURA-WYDANIA.md](PROCEDURA-WYDANIA.md) |
| Zmienić samą aplikację LinkTalk | [Repozytorium źródeł LinkTalk](https://github.com/DominikSolorz/LinkTalk) |

Wszystkie pliki APK są publikowane w [GitHub Releases](https://github.com/DominikSolorz/LinkTalk-Releases/releases), a nie bezpośrednio w `main`. Używaj nazw z numerem wersji, nigdy nie podmieniaj opublikowanego tagu w celu wydania nowej zawartości.

Zasady dla agentów: [../AGENTS.md](../AGENTS.md).
