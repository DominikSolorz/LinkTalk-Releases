# Krótkie nazwy zadań — 03 / LinkTalk-Releases

To repozytorium zawiera publiczne wydania plików instalacyjnych, a nie edytowalny kod aplikacji. Pliki APK znajdują się w **Releases**, nie w zwykłych plikach na `main`.

| Powiedz agentowi | Co zrobić |
| --- | --- |
| `LTR-WYDANIA` | Sprawdź https://github.com/DominikSolorz/LinkTalk-Releases/releases |
| `LTR-APK` | Przygotuj nowy plik Android z potwierdzonego źródłowego commita repo `DominikSolorz/LinkTalk` |
| `LTR-WERSJA` | Nadaj niepowtarzalny tag `vX.Y.Z` lub `vX.Y.Z-preview.N`; nie nadpisuj starego |
| `LTR-OPIS` | Dopisz do wydania datę, zmiany, wymagania, numer źródłowego commita |
| `LTR-KONTROLA` | Porównaj SHA-256 rzeczywiście zbudowanego pliku, sprawdź podpis jeśli jest deklarowany |
| `LTR-POBIERANIE` | Sprawdź publiczny URL assetu w GitHub Releases i poprawne pobranie |

Najpierw kod i testy w `DominikSolorz/LinkTalk`; potem numer/tag/plik APK w tym repozytorium. HOME SECURITY nie ma tu żadnych instalatorów.
